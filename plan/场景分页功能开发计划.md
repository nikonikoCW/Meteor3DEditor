# 场景列表分页功能开发计划

## 目标

为 ScenesView.vue 添加分页功能，支持大量场景的高效展示。

---

## 开发范围

### 需要修改

| 位置 | 文件 | 改动 |
|------|------|------|
| 前端 | `ScenesView.vue` | 添加分页状态、分页组件、分页逻辑 |
| 前端 | `sceneService.js` | `getScenes` 支持分页参数 |
| 后端 | `scene.controller.js` | 列表接口支持 page/pageSize 参数 |

---

## 任务清单

### Phase 1: 后端 API 改造

- [ ] 1.1 修改 `/scene/list` 接口
  - 接收 `page` 和 `pageSize` 参数
  - 返回 `{ scenes, total, page, pageSize }`

### Phase 2: 前端 Service 改造

- [ ] 2.1 修改 `getScenes(page, pageSize)`
  - 传递分页参数
  - 返回包含 `total` 的结构

### Phase 3: ScenesView.vue 改造

- [ ] 3.1 添加分页状态
  - `currentPage`, `pageSize`, `total`

- [ ] 3.2 添加分页组件 UI
  ```
  < 上一页  1 2 3 4 5  下一页 >
  ```

- [ ] 3.3 页码切换时重新加载数据

---

## API 设计

### 请求

```
GET /scene/list?page=1&pageSize=12
```

### 响应

```json
{
  "success": true,
  "scenes": [...],
  "pagination": {
    "page": 1,
    "pageSize": 12,
    "total": 56,
    "totalPages": 5
  }
}
```
