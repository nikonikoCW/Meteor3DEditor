# 安装

## NPM

```bash
npm install @meteor3d/core
```

## CDN

```html
<script type="module">
import { loadScene } from 'https://unpkg.com/@meteor3d/core/dist/index.esm.js';
</script>
```

## 依赖

Meteor3D SDK 依赖 Three.js，会自动安装，无需手动安装。

## 浏览器支持

- Chrome 80+
- Firefox 75+
- Safari 14+
- Edge 80+

需要支持 ES Modules 和 WebGL 2.0。
